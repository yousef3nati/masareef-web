# مصاريفي (نسخة الآيفون)

1. Settings > Pages > Branch: main / (root) > Save
2. بعد دقيقتين الرابط: https://yousef3nati.github.io/masareef-web/
3. على الآيفون: افتح الرابط بـ Safari > زر المشاركة > Add to Home Screen
4. افتحه دايماً من الأيقونة (مش من Safari)

مصاريفك بتضل على التلفون بس. طلبات البيت والالتزامات بتتزامن مع أهل البيت.
